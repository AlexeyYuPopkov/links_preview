# links_preview

Backend-сервис на Rust для предпросмотра ссылок (links preview).

## Описание
Этот сервис предназначен для получения и обработки метаданных по URL (заголовок, описание, изображение и др.) для формирования предпросмотра ссылок.

## Запуск

1. Установите Rust: https://www.rust-lang.org/tools/install
2. Склонируйте репозиторий и перейдите в папку проекта.
3. Соберите проект:
   ```sh
   cargo build
   ```
4. Запустите сервер:
   ```sh
   cargo run
   ```

## Структура
- `src/` — исходный код
- `Cargo.toml` — конфигурация проекта
- `README.md` — описание и инструкции
